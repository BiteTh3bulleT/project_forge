# Micro-Agent Acceleration

Status: `DESIGN_ONLY / PROPOSAL_CACHE_ADVISORY_ONLY / NO_LIVE_AUTHORITY_CHANGE`

This document defines the M5A Phase 7 design lane for background micro-agents that can reduce perceived latency without becoming hidden authority. The design is intentionally conservative: every worker may observe, precompute, rank, summarize, draft, cache, or propose. No worker may commit canonical truth, approve actions, mutate host state, execute tools directly, call modelruntime outside governance, write canonical memory, bypass Gateway, bypass Control Lane, bypass modelruntime governance, or bypass audit.

## Shared Contract

| Field | Requirement |
| --- | --- |
| Authority | Proposal/cache/advisory only. The Kernel, Control Lane, Gateway, modelruntime, approvals, and audit retain live authority. |
| Storage | Store only bounded metadata, cache entries, draft packets, and provenance-linked summaries. No raw prompts, raw host dumps, raw logs, secrets, or unbounded content. |
| Visibility | Every output must be labeled as `proposal`, `cache`, `advisory`, `not_wired`, `stale`, or `failed`; missing data must not be displayed as healthy. |
| Audit | Every worker run gets a worker run id, trigger source, input refs, output refs, cache key, TTL, status, duration, and correlation/trace ids when available. |
| TTL | Every cache must expire. Stale entries can be shown only with age and stale reason. |
| Failure | Fail closed into `unavailable` or `not_wired`; never retry unboundedly or block the live authority path. |
| Anti-loop | Workers must not trigger themselves from their own output. A run must carry a bounded depth/hop counter and a dedupe key. |
| Model calls | Optional and governed only. Prefer deterministic rules; if a model is used, its output is evidence/proposal only. |

## Runtime Preflight Agent

| Section | Design |
| --- | --- |
| Trigger | Modelruntime config change, model import/registration event, backend health refresh interval, or operator opening a modelruntime status view. |
| Input | Model id/backend refs, modelruntime config refs, backend health metadata, scheduler limits, safe-mode flags, and previous preflight cache key. |
| Output | Advisory preflight report: backend reachable/unreachable, model compatibility class, likely policy blockers, expected queue admission posture, and explicit `not_wired` fields. |
| Storage target | Ephemeral runtime preflight cache table or in-memory bounded cache; optional durable report only as non-canonical operational evidence. |
| Authority boundary | Cannot load/unload models, start processes, change backend config, select final model, approve requests, or alter modelruntime policy. |
| Cache TTL | 30 seconds for backend health, 5 minutes for static compatibility checks, immediate invalidation on model registry/config changes. |
| Audit/provenance | Record worker run id, model id, backend id, config fingerprint, health snapshot id, stale age, and correlation id. |
| Failure behavior | Return `preflight_unavailable` with source error summary; live modelruntime still makes the final decision. |
| Anti-loop guard | Dedupe by `runtime_preflight:{model_id}:{backend}:{config_hash}`; max one active run per key; ignore reports generated by this worker as triggers. |
| Tests required | Deterministic cache key tests, TTL expiry tests, no load/unload mutation tests, source-error visibility tests, and modelruntime decision-equivalence tests proving preflight cannot authorize execution. |

## Retrieval Pre-Rank Agent

| Section | Design |
| --- | --- |
| Trigger | Context compile request draft, retrieval run creation, operator search intent, or idle refresh for recently accessed workspace scopes. |
| Input | Query shape, workspace id, allowed source refs, retrieval index metadata, previous result refs, and policy limits. |
| Output | Ranked candidate refs with scores and explanations. Output is candidate ordering only, not truth. |
| Storage target | Bounded retrieval ranking cache keyed by workspace/query/source fingerprint. Store refs, scalar scores, and provenance; do not store raw document bodies. |
| Authority boundary | Cannot execute canonical retrieval admission, mutate memory, write facts, update source truth, or bypass retrieval/search policy. |
| Cache TTL | 2 minutes for interactive query rankings; 15 minutes for stable source-ref pre-ranks; invalidate on source index version change. |
| Audit/provenance | Record query fingerprint, source index version, candidate count, score version, run id, and trace/correlation ids. |
| Failure behavior | Return `ranking_unavailable`; downstream retrieval uses normal deterministic retrieval path. |
| Anti-loop guard | Dedupe by normalized query/source fingerprint; never re-rank its own candidate list unless the source index version changes. |
| Tests required | Ref-only storage tests, no raw content capture tests, deterministic ordering tests, stale invalidation tests, and no memory-write tests. |

## Context Precompile Agent

| Section | Design |
| --- | --- |
| Trigger | Recent thread activity, explicit context compile request, known restore snapshot candidate, or low-priority idle window. |
| Input | Workspace id, lane id, query fingerprint, current context refs, restore candidate refs, and context compiler policy. |
| Output | Draft ContextBundle/cache candidate labeled `precompiled_context_candidate`; final request still runs through the live context compiler/Control Lane path. |
| Storage target | Non-canonical context cache with bundle hash, input refs, compiler version, TTL, and provenance. Snapshots remain shape/restoration evidence, not truth. |
| Authority boundary | Cannot write canonical memory, admit evidence, decide truth, call modelruntime directly, or replace live `COMPILE_CONTEXT` validation. |
| Cache TTL | 5 minutes for interactive thread context; 30 minutes for stable restore candidates; invalidate on relevant memory/source version changes. |
| Audit/provenance | Record context input refs, compiler version, bundle hash, token budget estimate, run id, and source object version refs. |
| Failure behavior | Return `precompile_unavailable`; live compile path performs a fresh compile. |
| Anti-loop guard | Dedupe by `context_precompile:{workspace}:{lane}:{query_hash}:{source_version}`; do not trigger from precompiled bundle creation events. |
| Tests required | Cache identity tests, source-version invalidation tests, no canonical memory mutation tests, stale bundle rejection tests, and equivalence tests showing live compile can ignore the cache. |

## Approval Packet Drafter

| Section | Design |
| --- | --- |
| Trigger | A governed action reaches `approval_required`, an operator opens an approval queue, or a high-risk dry-run requests packet preview. |
| Input | Approval-required decision, action definition, actor/source/workspace, target refs, payload shape hash, risk class, existing approval request id when present. |
| Output | Draft approval packet with summary, risk reasons, required reviewer fields, evidence refs, and deterministic approval fingerprint preview. |
| Storage target | Draft packet store linked to approval request id or dry-run id. Store payload shape hashes and refs, not raw secrets or unbounded payloads. |
| Authority boundary | Cannot approve, reject, extend, expire, execute, or mutate the underlying request. Cannot create a backdoor approval id. |
| Cache TTL | 15 minutes for drafts without approval request id; same expiry as the linked approval request for request-bound drafts. |
| Audit/provenance | Record approval request id, fingerprint hash/version, payload shape hash, drafter version, worker run id, and reviewer visibility state. |
| Failure behavior | Approval flow still requires human/operator decision; missing draft appears as `draft_unavailable`. |
| Anti-loop guard | Dedupe by approval request id plus fingerprint hash; draft updates cannot trigger new approval decisions or new drafts unless fingerprint changes. |
| Tests required | Fingerprint determinism tests, no approve/reject mutation tests, missing approval service tests, secret redaction tests, and expiry alignment tests. |

## Artifact Summarizer

| Section | Design |
| --- | --- |
| Trigger | Artifact creation, operator opens artifact detail, trace report request, or idle summarization queue. |
| Input | Artifact refs, artifact metadata, bounded excerpts if policy allows, provenance refs, and summary policy. |
| Output | Advisory artifact summary, tags, and relation hints. Summary is not canonical truth and does not replace exact artifact evidence. |
| Storage target | Artifact summary cache linked by artifact id/version hash. Store summary text within a strict byte limit and source refs. |
| Authority boundary | Cannot alter artifact content, update canonical memory, admit evidence, delete artifacts, or mark artifacts authoritative. |
| Cache TTL | 24 hours or until artifact version/provenance hash changes, whichever comes first. |
| Audit/provenance | Record artifact id/version, summary model/rule version, input byte count, output byte count, run id, and source refs. |
| Failure behavior | Show `summary_unavailable`; artifact remains accessible by exact evidence path. |
| Anti-loop guard | Summaries cannot summarize summaries unless explicitly requested with depth 1; summary creation events do not enqueue new summaries. |
| Tests required | Version invalidation tests, byte-limit tests, no artifact mutation tests, no summary-as-truth tests, and provenance-link tests. |

## HostBridge/FORGE-H Sampler

| Section | Design |
| --- | --- |
| Trigger | System status refresh, safe-mode status request, modelruntime backend profile inspection, or bounded periodic timer when cockpit is open. |
| Input | HostBridge snapshot request policy, previous snapshot id, FORGE-H policy version, safe-mode flags, and source availability metadata. |
| Output | Cached HostBridge snapshot summary and FORGE-H advisory posture/proposals with age, stale state, source errors, and unavailable fields. |
| Storage target | Ephemeral snapshot cache plus optional bounded diagnostic report. Raw host dumps and raw command output are forbidden. |
| Authority boundary | Cannot run host mutation commands, call `systemctl` for mutation, run `nixos-rebuild`, execute FORGE-H proposals, change modelruntime load/unload state, or write semantic memory. |
| Cache TTL | 10 seconds for interactive cockpit display; 60 seconds for background advisory posture; stale allowed only with explicit age and source-error state. |
| Audit/provenance | Record snapshot id, capture time, source error count, FORGE-H policy id, proposal ids, worker run id, and route/request correlation id when present. |
| Failure behavior | Return last cache only if marked stale with age; otherwise `hostbridge_unavailable` and `forgeh_advisory_unavailable`. |
| Anti-loop guard | Dedupe sampler runs by wall-clock bucket and request class; status page refreshes do not spawn more than one active sample per TTL window. |
| Tests required | TTL/stale age tests, command-mutation forbidden tests, source-error preservation tests, no execution tests, and status payload missing-data tests. |

## Model Compatibility Precheck Agent

| Section | Design |
| --- | --- |
| Trigger | Model import/register, model manifest scan, backend profile change, or operator opens model detail/compatibility view. |
| Input | Model manifest refs, backend profile metadata, file checksum metadata, capability declarations, scheduler limits, GPU/safe-mode advisory posture. |
| Output | Advisory compatibility precheck report with supported capabilities, likely blockers, missing metadata, and backend fit. |
| Storage target | Compatibility cache keyed by model id, manifest hash, backend profile hash, and policy version. |
| Authority boundary | Cannot register/import/delete files, enable/disable/archive/load/unload models, bypass modelruntime governance, or make final runtime selection. |
| Cache TTL | 30 minutes for manifest/backend compatibility; invalidate on manifest hash, backend profile, or policy version change. |
| Audit/provenance | Record model id, manifest hash, backend profile hash, policy version, worker run id, source refs, and stale reason. |
| Failure behavior | Return `compatibility_precheck_unavailable`; modelruntime compatibility and policy checks remain authoritative. |
| Anti-loop guard | Dedupe by model/backend/policy hash; precheck reports do not trigger imports or new prechecks unless an input hash changes. |
| Tests required | Cache-key determinism tests, invalidation tests, no lifecycle mutation tests, missing metadata visibility tests, and modelruntime final-decision tests. |

## Implementation Gates

1. Land the M5A authority matrix before wiring any worker.
2. Define cache schemas with TTL, stale state, bounded size, and provenance.
3. Add worker run audit records before background scheduling.
4. Implement one worker at a time behind disabled-by-default flags.
5. Prove no worker can mutate canonical memory, approve actions, execute tools, mutate host state, or change modelruntime lifecycle.
6. Expose worker output only as advisory/cache/proposal with `not_wired`, `unavailable`, `failed`, and `stale` states preserved.
