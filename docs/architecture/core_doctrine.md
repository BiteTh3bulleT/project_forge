# FORGE-K Core Doctrine

Status: Phase 0 architecture baseline.

## Read This If You Want

Read this if you want the compact FORGE-K doctrine: the permanent authority rules, control models, and short-form boundaries that other architecture docs expand.

FORGE-K is a deterministic cognitive microkernel. The model is not the operating system. The model is a driver attached to the operating system. FORGE-K owns truth.

## Permanent Doctrine

- Neural neurons propose.
- Rule neurons validate.
- Courthouse admits.
- Kernel commits.
- Palace retrieves.
- Algebra transforms.
- Snapshots preserve shape.
- Compiler shapes context.
- KV accelerates.
- Lymphatic cleans.
- Journal remembers.

## Control Models

FORGE-K uses the Three-Domain Control Model:

- Truth domain: canonical state, journaled semantic transitions, admitted rulings, and committed syscall results.
- Shape domain: context shape, snapshots, routes, summaries, restore hints, and prompt layout.
- Acceleration domain: KV cache, cache manifests, token hashes, and runtime-specific reuse artifacts.

FORGE-K uses the Six-State Lifecycle Model:

1. Proposed
2. Submitted
3. Validated
4. Admitted
5. Committed
6. Retired

Retired includes superseded, expired, archived, or contradiction-marked objects. Retirement preserves inspectability and provenance.

## Authority Rules

- Model output is proposal material only.
- Rule output is validation material only.
- Courthouse output is admissibility material.
- Kernel syscall output is the only canonical mutation path.
- Raw tool results are evidence, not truth.
- Snapshots are shape records, not truth records.
- KV cache is acceleration, not memory.

## What FORGE-K Is Not

FORGE-K is not:

- a chatbot wrapper
- a normal RAG app
- a bare-metal OS yet
- a model pretending to be memory
- a cache pretending to be memory
- raw conversation replay
- uncontrolled tool execution

## Engineering Requirements

- Keep runtime drivers outside the authority boundary.
- Keep the hot path small.
- Defer maintenance work to the Lymphatic Lane unless it blocks correctness.
- Preserve provenance through every object transformation.
- Treat compression, summarization, and ranking as derived shape unless committed through semantic syscalls.
- Record rejection reasons, contradiction records, and supersession links instead of overwriting history.
