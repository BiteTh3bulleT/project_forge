# Status Flags

Use these exact status markers in docs and phase reports:

- `SIMULATOR_ONLY`
- `SHADOW_READ_ONLY`
- `VALIDATION_ONLY`
- `PARTIAL_LIVE_VALIDATION`
- `PARTIAL_LIVE_ENFORCEMENT`
- `DISABLED_BY_DEFAULT_LIVE`
- `OPERATOR_APPROVED_LIVE`
- `DEFAULT_LIVE`
- `LEGACY_PATH_RETIRED`
- `DESIGN_ONLY`
- `DOCS_ONLY`
- `READINESS_REVIEW`
- `BLOCKED`
- `DEFERRED`
- `NO_LIVE_AUTHORITY_CHANGE`

Never invent softer language like "basically live". It either is live, or it is not. Civilization depends on this tiny act of mercy.
