## Live integration-ready shared contracts

Create or extend shared packages outside `services/core/internal/forgek` for:

- ref validation
- semantic operation validation
- KV identity validation
- source object authority validation
- evidence ref validation
- context block validation
- journal event validation
- capability predicate validation

## Rule

Shared contracts may be used by live owners. Simulator services may not become live owners without explicit migration.
