# Glossary

## FORGE-K

The target deterministic cognitive microkernel for semantic truth governance.

## Kernel

The only target component that commits canonical semantic state after validation and admission.

## Courthouse

Evidence admission layer. Decides what evidence may enter context or commit review.

## Memory Palace

Evidence topology and retrieval organization layer.

## Context Compiler

Compiles admitted evidence into inspectable prompt/context bundles.

## Modelruntime

Live model driver governance. It generates proposals/evidence, not truth.

## Gateway

Live tool execution authority.

## Lymphatic Lane

Maintenance lane for proposal-first cleanup, contradiction sweeps, and hygiene.

## Consensus Mesh

Claim/action governance layer before response/action composition.

## NixOS substrate

Declarative host system layer. FORGE-K must not bypass it for host mutation.
