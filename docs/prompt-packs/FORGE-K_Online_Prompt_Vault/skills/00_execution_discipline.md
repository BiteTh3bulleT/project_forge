# Skill: Execution Discipline

## Purpose

Apply this skill during FORGE-K online migration work.

## Operating rules

- Stay inside the current phase scope.
- Identify live authority owner before editing.
- Prefer shared pure contracts over simulator imports.
- Add validation evidence.
- Preserve rollback.
- Update docs when behavior or status changes.

## Inputs

- Current phase prompt
- `AGENTS.md`
- `ai_context/CURRENT_TRUTH.md`
- `ai_context/AUTHORITY_BOUNDARIES.md`
- Relevant architecture doc

## Output

- Narrow implementation or documentation update
- Tests
- Phase report
- Known blockers

## What not to do

- Do not broaden scope.
- Do not claim live authority without tests.
- Do not hide failed validation.
