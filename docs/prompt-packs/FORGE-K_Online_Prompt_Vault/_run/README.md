# Run Helper Folder

This folder explains how to use the vault.

## Use as Obsidian vault

Open the root folder `FORGE-K_Online_Prompt_Vault` in Obsidian.

## Use in repo

Copy the folders you want into the repo. Merge carefully. Do not blindly overwrite existing `AGENTS.md`, `.cursor/rules`, or docs.

## Recommended repo import

- copy `prompts/` into repo `docs/prompts/forge-k-online/` or `prompts/forge-k-online/`
- copy `.cursor/rules/*.mdc` into repo `.cursor/rules/`
- copy selected process docs into `docs/process/`
- copy ADR templates into `docs/adr/`

See `_run/validate_pack.md`.
