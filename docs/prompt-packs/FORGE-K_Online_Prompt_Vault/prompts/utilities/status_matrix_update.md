# Status Matrix Update Prompt

Update authority/status docs after a phase.

## Required docs to inspect

- `docs/reviews/current_phase_status.md`
- `docs/status/current_authority_sources.md`
- `docs/status/implementation_matrix.md`
- relevant architecture docs
- relevant ADRs

## Output

- exact status marker
- authority impact
- tests/evidence
- remaining blockers

## WHAT NOT TO DO

Do not overclaim live authority.
