# Do Not Touch Without Explicit Phase Approval

- Live route/API shapes
- Gateway execution semantics
- Permissions/lanes approval policy
- Modelruntime backend behavior
- Retrieval execution behavior
- Embedding provider calls
- Memory write paths
- NixOS host mutation commands
- Tauri shell host-power paths
- Storage backend default
- Qdrant live retrieval authority
- Redis canonical state
- Simulator services as live authority

## Break-glass rule

If a change seems necessary in one of these areas, stop and produce a phase-blocker report instead of improvising.
