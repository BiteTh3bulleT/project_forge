# FORGE-K Online Strategy

## Goal

Promote FORGE-K from simulator/shadow/validation layers into live operational semantic authority, one governed seam at a time.

## Online ladder

```text
SIMULATOR_ONLY
→ SHADOW_READ_ONLY
→ VALIDATION_ONLY
→ DISABLED_BY_DEFAULT_LIVE
→ OPERATOR_APPROVED_LIVE
→ DEFAULT_LIVE
→ LEGACY_PATH_RETIRED
```

No phase may skip this ladder.

## Target live model

- NixOS owns host substrate.
- Gateway owns tool execution.
- Modelruntime owns runtime drivers.
- FORGE-K owns semantic truth flow.
- Operator owns dangerous authority.
