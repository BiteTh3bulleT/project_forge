# Courthouse and Memory Palace Online Path

## Memory Palace

Finds evidence candidates and organizes retrieval topology.

## Courthouse

Admits or rejects evidence for context/commit review.

## Rule

Retrieval does not make truth. Embedding similarity does not make truth. Model confidence does not make truth. User text is evidence, not automatic truth.

## Live migration path

1. Mirror existing retrieval/memory metadata.
2. Normalize evidence refs.
3. Create CasePacket envelopes.
4. Run admission decisions.
5. Gate context inclusion.
6. Later, route canonical memory writes through Kernel commit path.
