# Consensus Gate

## Purpose

Gate claims and action proposals before final response or live action proposal surfaces.

## Required behavior

- extract claims
- score evidence support
- detect conflicts
- apply risk policy
- block unsupported high-risk claims
- disclose unresolved conflict
- keep consensus separate from canonical truth

## No Consensus, No Claim

High-confidence factual, operational, or action claims must not enter final response shape without consensus/admission policy.
