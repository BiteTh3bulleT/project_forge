# FORGE Security Doctrine

- Local-first does not mean unauthenticated.
- Loopback is not an auth boundary.
- CORS is not auth.
- Client-side login is not backend auth.
- Body actor strings are claims, not identity.
- High-risk approval requires authenticated authority.
- Host mutation requires proposal, approval, build/test evidence, and rollback.
- Model output is evidence, not truth.
- Gateway owns tool execution.
- Control Lane owns canonical semantic mutation.
