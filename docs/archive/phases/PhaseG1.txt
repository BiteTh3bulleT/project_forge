# FORGE Phase G1 — Graphical Shell Session Foundation

You are working in the `project_forge` repository.

FORGE is evolving into the actual graphical shell interface for a NixOS-based FORGE-OS machine.

This does NOT mean a web dashboard controlling a headless server.
This means FORGE becomes the visible graphical operating interface: the desktop shell, launcher, workspace surface, command center, and system context surface.

NixOS remains the substrate.
FORGE becomes the graphical shell.

## Goal

Create the foundation for a FORGE graphical shell session.

G1 must define and scaffold a NixOS graphical session that launches FORGE as the primary shell interface, while preserving all existing FORGE authority boundaries.

This phase should be safe, incremental, and non-destructive.

## Doctrine To Preserve

- FORGE is the AI-OS operating environment.
- NixOS/Linux remains the boot, hardware, display, and service substrate.
- FORGE is the graphical shell session, not a normal desktop app.
- FORGE shell must talk to `forge-core` through governed local APIs/interfaces.
- FORGE shell must not directly mutate host state.
- FORGE shell must not bypass gateway, permissions, lanes, audit, controllane, memory, modelruntime, FORGE-K, FORGE-H, or approval authority.
- FORGE-H N3-N6 resource diagnostics/policy/proposals/executions remain governed and bounded.
- No host mutation, service restarts, NixOS rebuilds, kernel/module changes, model loads/unloads, or direct semantic memory writes may be introduced in G1.

## Concept

The intended stack:

Hardware
  ↓
Linux kernel
  ↓
NixOS
  ↓
Display/session layer
  ↓
FORGE graphical shell
  ↓
forge-core / FORGE-H / HostBridge / memory / journal / approvals
  ↓
Robert

FORGE should become the operator-facing shell.

## Session Model

Define a FORGE graphical shell session.

The first implementation should support one safe launch mode:

- `fullscreen-shell`

Future modes may include:

- `kiosk`
- `compositor-integrated`
- `remote-operator`
- `multi-monitor-shell`

G1 only scaffolds `fullscreen-shell`.

Do not enable autologin by default.
Do not replace the user’s desktop by default.
Do not disable existing desktop environments by default.

G1 must be opt-in.

notification area

But G1 does not need to implement all of these.

G1 should only define the contract and create the session launch path.

Existing Desktop App

If the repo already has a desktop/Tauri shell, do not rewrite it.

Instead:

identify the current desktop shell entrypoint
document how it maps to the FORGE graphical shell
add session scaffolding that can launch the existing shell package/binary when available
if packaging is incomplete, create TODO-safe scaffolding and docs rather than fake production behavior
Shell-to-Core Boundary

FORGE shell must access system state through forge-core.

Allowed:

read host diagnostics through existing safe/internal paths if available
read FORGE-H policy/proposal/execution records through governed paths if available
show service/resource status
show approval queue if existing APIs support it
show shell-safe status placeholders if APIs are not available yet

Forbidden:

direct systemctl
direct nixos-rebuild
direct kernel/module calls
direct modelruntime load/unload
direct filesystem cleanup
direct semantic memory writes
direct gateway execution bypass
System Context Principle

Document this principle clearly:

FORGE as graphical shell provides full operating awareness, not full LLM context.

The shell may observe structured system/session context:

active workspace
open panels/windows
current project
resource posture
service health
model status
approvals
recent errors
user-triggered actions

The context compiler decides what subset reaches the LLM.

Do not dump raw full system state into model prompts.

WHAT NOT TO DO
Do not build a fake web dashboard and call it the shell.
Do not replace the user’s desktop by default.
Do not enable autologin by default.
Do not require KDE, GNOME, or a full desktop environment.
Do not implement a custom compositor in G1.
Do not add direct host controls to the shell.
Do not run systemctl start/stop/restart.
Do not run nixos-rebuild.
Do not load or unload kernel modules.
Do not reboot or shut down the machine.
Do not install, remove, or upgrade packages.
Do not load or unload models.
Do not spawn model runtimes.
Do not write directly to semantic memory.
Do not bypass gateway, permissions, lanes, audit, controllane, memory, modelruntime, FORGE-H, or FORGE-K authority.
Do not make this a public/SaaS/multi-user shell.
