# FORGE Phase G3 — Nix-Packaged FORGE Desktop Shell

You are working in the `project_forge` repository.

Phase G1 created the FORGE graphical shell session foundation.
Phase G2 added a safe `forge-shell-session` wrapper that launches an existing local Tauri `forge_desktop` binary when available.

Now implement Phase G3: package the actual FORGE desktop/Tauri shell as a Nix package and wire the shell session wrapper to use it when available.

## Goal

Create a Nix-buildable package for the FORGE graphical shell binary.

The target flow should become:

```bash
nix build .#forge-desktop-shell
nix run .#forge-shell-session

forge-shell-session should prefer the Nix-built FORGE desktop shell package when configured, while preserving the current safe fallback behavior from G2.

Doctrine To Preserve
FORGE is the graphical shell interface.
NixOS/Linux remains the substrate.
G3 must not replace the desktop.
G3 must not enable autologin.
G3 must not install or require a compositor.
G3 must not implement a custom compositor.
G3 must not mutate host state.
G3 must not run systemd control commands.
G3 must not run nixos-rebuild.
G3 must not load/unload models.
G3 must not write semantic memory directly.
G3 must not bypass gateway, permissions, lanes, audit, controllane, memory, modelruntime, FORGE-H, or FORGE-K authority.

Nix Package Requirements

Create nix/packages/forge-desktop-shell.nix.

It should attempt to build the desktop shell using the repo’s existing Tauri/frontend build process.

Expected output:

/bin/forge_desktop

or a wrapper with a clear stable command:

/bin/forge-desktop-shell

If the actual Tauri binary name remains forge_desktop, provide a stable wrapper command too:

/bin/forge-desktop-shell

The wrapper should launch the Tauri binary with safe shell-mode environment defaults.

Safe Environment Defaults

The desktop shell package/wrapper must preserve:

FORGE_SHELL_SESSION_ENABLED=true
FORGE_SHELL_MODE=fullscreen-shell
FORGE_CORE_URL=http://127.0.0.1:18492
VITE_FORGE_API_URL=$FORGE_CORE_URL
FORGE_SHELL_SAFE_MODE=true
FORGE_SHELL_FULLSCREEN=true
FORGE_SHELL_HOST_MUTATION=false
FORGE_SHELL_DIRECT_SYSTEM_CONTROL=false
FORGE_SHELL_MODEL_MUTATION=false
FORGE_SHELL_SEMANTIC_MEMORY_WRITE=false
FORGE_SHELL_FORGE_K_LIVE_AUTHORITY=false

Allow FORGE_CORE_URL override through the environment.

Update nix/packages/forge-shell-session.nix so it can use the packaged desktop shell.
