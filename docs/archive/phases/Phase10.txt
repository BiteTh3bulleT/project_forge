Goal:

Build the FORGE-K Lymphatic Lane inside `services/core/internal/forgek`.

The Lymphatic Lane is the simulator maintenance, hygiene, coherence, and anti-rot system.

It should detect stale, expired, orphaned, contradicted, superseded, invalidated, or cleanup-eligible simulator objects and produce deterministic maintenance reports and cleanup proposals.

It must not silently delete canonical truth.
It must not mutate source objects without syscalls.
It must not wire into live daemon cleanup.
It must not run automatically in the live runtime.

Core doctrine:

- Lymphatic Lane cleans, audits, proposes, expires, compacts, and reports.
- Lymphatic Lane does not own truth.
- Lymphatic Lane does not bypass Kernel authority.
- Cleanup proposals are not canonical mutations until committed through semantic syscalls.
- Superseded, rejected, invalidated, and expired objects remain inspectable.
- Provenance must never be destroyed.
- Lymphatic sweeps must be deterministic for stable inputs.
- Maintenance reports are evidence/proposals, not final authority.
- Cache eviction does not delete memory.
- Snapshot expiration does not delete source truth.
- Runtime output aging does not delete model evidence.
- Contradiction sweeps must not silently merge contradictions.
