# FORGE Phase G4 — Wayland Shell Session Integration

You are working in the `project_forge` repository.

Phase G3.5 is complete. It may have been mislabeled as G4 in local notes, but the actual completed work is:
- `packages.forge-desktop-shell`
- `apps.forge-desktop-shell`
- real Tauri/Nix desktop shell package
- `passthru.containsTauriBinary = true`
- `forge-shell-session` prefers the packaged shell when available

Now implement the actual Phase G4: Wayland Shell Session Integration.

## Goal

Wire the packaged FORGE graphical shell into an actual opt-in NixOS Wayland shell session.

Target flow:

NixOS login/session selection
  → FORGE Shell Session
  → lightweight Wayland substrate
  → `forge-shell-session`
  → `forge-desktop-shell`
  → local `forge-core`

FORGE becomes the graphical shell interface.
NixOS/Linux remains the substrate.

## Doctrine

- FORGE is the graphical shell interface.
- NixOS/Linux remains the boot, hardware, service, package, and display substrate.
- G4 must be opt-in.
- G4 must not enable autologin by default.
- G4 must not replace KDE/GNOME/other sessions by default.
- G4 must not remove normal desktop fallback.
- G4 must not remove TTY fallback.
- G4 must not mutate host state directly.
- G4 must not run `systemctl` control commands from shell code.
- G4 must not run `nixos-rebuild`.
- G4 must not load/unload kernel modules.
- G4 must not load/unload models.
- G4 must not write semantic memory directly.
- G4 must not bypass gateway, permissions, lanes, audit, controllane, memory, modelruntime, FORGE-H, or FORGE-K authority.

## Required Session Model

Add support for an opt-in Wayland shell session.

Preferred substrate:

- Cage, if cleanly available through Nixpkgs

Conceptual launch:

```text
cage -- forge-shell-session

The session should use forge-shell-session, not bypass it, because forge-shell-session already owns the safe shell environment and packaged shell selection.

Create a real session descriptor where appropriate.

Package / Wrapper

If adding a package like forge-wayland-session, it should provide:

/bin/forge-wayland-session

It should:

Set/confirm safe shell environment variables.
Launch the configured lightweight Wayland compositor.
Launch forge-shell-session inside it.
Fail loudly if the compositor or shell binary is unavailable.
Never run host mutation commands.

Preferred selection:

forge-wayland-session
  → cage
  → forge-shell-session
  → forge-desktop-shell

Safety / Fallback

Preserve fallback paths:

manual nix run .#forge-desktop-shell
FORGE_SHELL_BINARY=/path/to/forge_desktop

no deletion or migration of /forge

Rollback must be documented clearly.

replacing display manager configuration without explicit opt-in
