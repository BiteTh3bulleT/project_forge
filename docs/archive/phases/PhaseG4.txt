# FORGE Phase G3.5 — Real Tauri Nix Build

You are working in the `project_forge` repository.

Phase G3 added the `forge-desktop-shell` package surface, but it is currently a launcher placeholder with `passthru.containsTauriBinary = false`.

Now implement Phase G3.5: build the actual FORGE Tauri desktop shell through Nix.

## Goal

Turn `packages.forge-desktop-shell` from a placeholder into a real Nix-built desktop shell package that contains the actual FORGE Tauri binary.

The target:

```bash
nix build .#forge-desktop-shell
nix run .#forge-desktop-shell
nix run .#forge-shell-session

forge-shell-session should then detect that forge-desktop-shell.passthru.containsTauriBinary = true and prefer the packaged shell before local fallback paths.
