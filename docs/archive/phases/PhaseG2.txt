# FORGE Phase G2 — Launchable Graphical Shell Package

You are working in the `project_forge` repository.

Phase G1 is complete. It added the FORGE graphical shell session foundation:
- `nix/nixos/modules/forge-shell-session.nix`
- `nixosModules.forge-shell-session`
- ADR/docs for FORGE as the graphical shell
- safe environment/session scaffolding
- disabled-by-default behavior
- placeholder desktop entry when no package is wired

Now implement Phase G2: make the FORGE graphical shell session launchable through a real Nix package/wrapper.

G2 should turn the G1 shell contract into a manually launchable shell command without replacing the user’s desktop, enabling autologin, installing a compositor, or mutating the host.

## Goal

Create a launchable `forge-shell-session` package/app that starts the existing FORGE desktop/shell UI in safe fullscreen shell mode and connects it to local `forge-core`.

The intended manual flow:

```text
nix run .#forge-shell-session

or, once imported into NixOS:

forge-shell-session

The shell should launch as FORGE’s graphical operator interface, not as a random web dashboard.

Doctrine To Preserve
FORGE is the graphical shell interface.
NixOS/Linux remains the substrate.
G2 must not replace the desktop.
G2 must not enable autologin.
G2 must not require KDE/GNOME.
G2 must not implement a custom compositor.
G2 must not mutate host state.
G2 must not run systemd control commands.
G2 must not run nixos-rebuild.
G2 must not load/unload models.
G2 must not write semantic memory directly.
G2 must not bypass gateway, permissions, lanes, audit, controllane, memory, modelruntime, FORGE-H, or FORGE-K authority.

Wrapper Behavior

The forge-shell-session command must:

Set safe environment variables.
Point to local forge-core.
Launch the existing FORGE graphical shell if available.
Prefer fullscreen/shell mode where supported.
Fail clearly if the shell binary/build output is unavailable.
Never run host mutation commands.

Required environment:

FORGE_SHELL_SESSION_ENABLED=true
FORGE_SHELL_MODE=fullscreen-shell
FORGE_CORE_URL=http://127.0.0.1:18492
FORGE_SHELL_SAFE_MODE=true
FORGE_SHELL_FULLSCREEN=true
FORGE_SHELL_HOST_MUTATION=false
FORGE_SHELL_DIRECT_SYSTEM_CONTROL=false
FORGE_SHELL_MODEL_MUTATION=false
FORGE_SHELL_SEMANTIC_MEMORY_WRITE=false
FORGE_SHELL_FORGE_K_LIVE_AUTHORITY=false

Allow FORGE_CORE_URL override through the environment, but default to:

http://127.0.0.1:18492
