Core doctrine:

- Shadow mode observes, mirrors, compares, and reports.
- Shadow mode does not affect live behavior.
- Shadow mode does not mutate live state.
- Shadow mode does not execute tools.
- Shadow mode does not call live model runtimes.
- Shadow mode does not perform live retrieval.
- Shadow mode does not write memory.
- Shadow mode does not alter user-visible output.
- Shadow reports are diagnostics only.
- Any future live shadow harness must remain read-only until a later LIVE_INTEGRATION phase explicitly authorizes more.
- RAG/retrieval shadowing is evidence/ref normalization only, not retrieval execution.
