Core doctrine:

- Shadow mode observes and reports only.
- Shadow diagnostics are non-authoritative.
- Shadow diagnostics must not affect live response behavior.
- Shadow diagnostics must not mutate live state.
- Shadow diagnostics must not execute tools.
- Shadow diagnostics must not call modelruntime.
- Shadow diagnostics must not perform retrieval/search/embedding calls.
- Shadow diagnostics must not write memory.
- Shadow diagnostics must not call controllane mutations.
- Shadow diagnostics must not create a second authority path.
- `FORGE_K_SHADOW_MODE_ENABLED` remains disabled by default.
- Chat metadata must also be disabled by default.
- Existing `/health` and route-envelope shadow behavior must remain unchanged.

Feature flags:

Keep existing:

- `FORGE_K_SHADOW_MODE_ENABLED=false`

Add a scoped flag if consistent with config style:

- `FORGE_K_SHADOW_CHAT_METADATA_ENABLED=false`

Rules:

- global shadow flag false disables all shadow work
- chat metadata flag false disables chat metadata even if global shadow is enabled
- chat metadata must never enable unless both global and chat-specific flags are true
- no public settings UI/API change in this phase unless existing private config pattern requires it
