5. Implement claim canonicalization.

Canonical claim key:

hash(claim_type + subject + predicate + normalized_value + scope + temporal_bucket)

Rules:

- equivalent values normalize to same claim key where practical
- numeric strings and numbers normalize consistently
- booleans normalize consistently
- scope is deterministic
- temporal bucket is deterministic
- map key order cannot affect claim key
- timestamps excluded unless part of temporal bucket

Tests:

- “three” and 3 may normalize only if explicit normalizer supports it; do not overbuild natural language.
- 3 and “3” should normalize if value type allows numeric normalization.
- same subject/predicate/scope/value creates same key.
- different value creates different key.
- different scope creates different key.

- same predicate
- overlapping scope
- overlapping temporal range/bucket
- different normalized values

Rules:

- uncertainty claims do not create hard conflicts by default

- memory update proposal conflicts compare target memory subject/predicate/scope
- conflict detection must be deterministic
