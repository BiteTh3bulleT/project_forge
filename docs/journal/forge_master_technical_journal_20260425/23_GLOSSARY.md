# Glossary

FORGE: Local-first cognitive operating system and governed AI engineering workspace.

IRIS: Future semantic intelligence service inside FORGE; proposer only.

GHOST: Conversation-derived bounded runtime intelligence concept.

ARTEMIS: Conversation-derived operator/perception cockpit concept.

AI-OS: Operating model where memory, authority, execution, audit, and cognition are governed by deterministic system boundaries.

Kernel: CPU/RAM control authority for canonical truth and semantic commits.

Semantic syscall: Deterministic request to mutate semantic memory/state through validation, approval, transaction, journal, and audit.

Control lane: Kernel lane that validates and commits semantic actions.

Cognitive filesystem: Durable semantic object store for notes, links, state, loops, artifacts, derived models, provenance, contradictions, supersessions, snapshots, and journal events.

Context snapshot: Non-canonical record of context assembly and restore evidence.

Restore scoring: Deterministic candidate ranking for context restore.

Dream Mode: Lymphatic dry-run maintenance and consolidation report engine.

Rule Cell: Future deterministic rule unit that emits proposals/routes/scores but does not mutate truth.

Hyperlane: Future low-latency routing substrate for Rule Cells and reflex decisions.

Gateway: Governed tool execution authority.

Modelruntime: Governed inference and model lifecycle authority.

Canonical truth: Current committed semantic state owned by kernel paths.

Non-canonical evidence: Records used for inspection, restore, or reasoning that do not themselves define truth.

Short/mid/long-term memory: Proposed memory tiering vocabulary; not fully canonicalized today.

Proposal: Candidate action or memory update awaiting validation.

Commit: Deterministic durable write through syscall transaction boundary.

Provenance: Actor/source lineage for a record.

Trace: Cross-system execution lineage.

Audit: Durable record of significant decisions, attempts, outcomes, and authority checks.
