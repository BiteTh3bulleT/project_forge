# System Identity

## What FORGE Is

IMPLEMENTED: FORGE is a local-first AI workspace and control system for inspectable, approval-gated engineering work.

DOCTRINE: FORGE is the OS. Models, adapters, future IRIS, rule agents, and Dream Mode are services inside the OS. They do not own canonical truth.

## Chatbot vs Agent Framework vs Cognitive OS

| Category | Description | FORGE Position |
|---|---|---|
| Chatbot | Conversational interface over a model | FORGE includes chat, but chat is not the authority model. |
| Agent framework | Plans and invokes tools | FORGE includes agents/autonomy concepts, but they must pass gateway/kernel gates. |
| Cognitive OS | Owns memory, authority, execution, audit, and operating posture | FORGE is explicitly designed as this layer. |

## Relationship To IRIS, GHOST, ARTEMIS

| System | Role | Status | Authority Level |
|---|---|---|---|
| FORGE | Kernel, truth owner, gateway, audit, local operating layer | PARTIAL / IMPLEMENTED foundation | Canonical authority |
| IRIS | Future semantic intelligence service inside FORGE | CONCEPT / SCAFFOLD source class | Proposer only |
| GHOST concepts | Bounded runtime intelligence and local reflex behavior | CONCEPT | Proposer only |
| ARTEMIS concepts | Operator/perception/cockpit surface | CONCEPT / partial UI analogs | Operator interface only |
| modelruntime | Governed inference substrate | IMPLEMENTED / PARTIAL M3 | Inference authority, not truth authority |
| gateway | Governed tool execution authority | IMPLEMENTED | Tool execution authority |
| Dream Mode | Lymphatic memory maintenance/report engine | PARTIAL v0 | Non-canonical proposal/evidence |
| Rule Cells / Hyperlane | Deterministic low-latency rule substrate | CONCEPT / PLANNED | Proposer/router only |

## Model-Agnostic And Future-Model-Ready

FORGE does not require a specific model to be correct. Kernel validators, syscall commits, approval gates, path checks, audit records, and restore scoring are deterministic CPU/RAM paths. Powerful models can improve planning, summarization, verification, and repair, but they cannot bypass authority.
